# Detectly – Real-time Object Detection

Detectly is a real-time object detection Android application built using **CameraX**, **Google ML Kit**, and **Jetpack Compose**. Designed for performance and accuracy, Detectly leverages modern Android development practices and real-time machine learning capabilities to detect and track objects seamlessly through the device camera.

## ✨ Features

- 🎯 **Real-time Object Detection** using Google ML Kit's Object Detection API.
- 📷 **CameraX Integration** for lifecycle-aware and efficient camera use.
- ⚡ **Optimized Frame Processing** achieving up to **35% performance improvement** through memory-efficient algorithms.
- 🧱 **MVVM Architecture** ensuring a clean, scalable, and maintainable codebase.
- 💅 **Modern UI** with Jetpack Compose for a reactive and smooth user experience.

## 🚀 Tech Stack

| Category           | Technology                |
